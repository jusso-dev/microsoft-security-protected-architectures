# Infrastructure as Code

Sample Infrastructure as Code (IaC) templates for deploying a core Microsoft Sentinel workspace in Australia East with private link, diagnostic settings and role-based access control.

All samples use placeholder identifiers only and must never be deployed to a production tenant without review against your organisation's security risk assessment and current ISM release.
