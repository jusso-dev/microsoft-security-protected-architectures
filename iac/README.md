# Infrastructure as Code

Sample Infrastructure as Code (IaC) templates for deploying a core Microsoft Sentinel workspace in Australia East with private link, diagnostic settings, resource locks and role-based access control.

All samples use placeholder identifiers only and must never be deployed to a production tenant without review against your organisation's security risk assessment and current ISM release.

## Available modules

- [Bicep sample](bicep/README.md): Log Analytics workspace, Microsoft Sentinel onboarding, AMPLS Private Link, Data Collection Endpoint, diagnostic settings, delete lock, RBAC and Deploy to Azure button
